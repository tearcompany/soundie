# Soundie — minimalny zakres (core loop)

## Sedno

Sedno Soundie jest proste.

**Soundie to też tonacja afirmacji** — obok uzdrawiającego dźwięku: język, który potwierdza, zamiast wyciskać.

**Soundie to też mechanizm intencji korelatywnej** — słuchanie nie jest pasywne: zostajesz z wyborem nuty, z czasem, z nastrojem; to powtarzalny ruch, który utrwala intencję.

Otwieram appkę.  
Słucham nuty 3 minuty.  
Czuję się lepiej.  
Nuta rośnie.  
Wracam jutro.

To już wystarczy.

To jest wręcz piękne.

---

## Core loop

1. User wchodzi
2. Wybiera nutę
3. Klik „Słuchaj”
4. 3–5 min sesji
5. Dostaje efekt / insight / lore unlock
6. Chce wrócić jutro

## Minimum funkcji

- auth (opcjonalnie magic link)
- 12 nut
- listening timer
- session history
- 1 unlock mechanika (zrealizowane: **lore w 5 warstwach** na nucie — progi łącznego czasu słuchania 0 / 15 / 30 / 60 / 120 min; po wejściu w nową warstwę baner + podświetlenie slajdu w karuzeli)
- dashboard
- mobile responsive
